# Topple Towers - Stacking Game
## Game Description
Topple Towers is a 3D stacking game where players place blocks to build the tallest possible tower. Each block has random dimensions and colors. The game features physics-based movement, where blocks sway, and increasingly as time goes on. 

## Features
Physics-Based Gameplay - Blocks sway and react realistically.

Randomized Blocks - Every block has a different size and color.

Preview Blocks - See what your next block will be before placing it.

Mobile & PC Support - Works with touch controls and mouse input.

Score Tracking - Try to beat your highest score.

## How to Play

Start the Game - Tap "Play" to begin.

Place Blocks - Tap (or click) to drop a block on top of the tower or platform.

Build Higher - Each new block is randomly sized, making placement tricky.

Avoid Collapse - If the tower tilts too far (more than 30 degrees), the game ends.

Restart the Game - Tap "Restart" to start the game again.
